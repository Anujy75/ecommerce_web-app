# 🛒 ShopEase - E-Commerce Web App

A full-stack e-commerce application built with **Spring Boot** and **React**. Features secure JWT-based authentication, product management, and a responsive user interface.

## 🛠️ Tech Stack

### Backend
| Technology | Purpose |
|------------|---------|
| Java 17 | Programming Language |
| Spring Boot 3.x | Framework |
| Spring Security | Authentication & Authorization |
| JWT (JJWT) | Token Generation & Validation |
| MySQL | Database |
| JPA/Hibernate | ORM Mapping |
| BCrypt | Password Encryption |
| Maven | Dependency Management |

### Frontend
| Technology | Purpose |
|------------|---------|
| React 18 | UI Library |
| React Router DOM | Routing |
| Axios | HTTP Requests |
| CSS-in-JS | Styling |
| LocalStorage | Token Storage |

### Tools & DevOps
- Git & GitHub
- Postman (API Testing)
- IntelliJ IDEA (Backend)
- VS Code (Frontend)
- MySQL Workbench
