# 🛒 ShopEase - E-Commerce Web App

A full-stack e-commerce application built with Spring Boot and React.

## 🛠️ Tech Stack

### Backend
- Java + Spring Boot
- Spring Security + JWT Authentication
- MySQL + JPA/Hibernate
- BCrypt Password Encryption

### Frontend
- React.js
- Axios
- React Router DOM

## 📁 Project Structure
- `main` — Project overview
- `backend` — Spring Boot REST APIs
- `frontend` — React UI

## ✅ Features
- User Registration & Login
- JWT Authentication
- Protected Routes
- BCrypt Password Encryption
- Responsive UI
